# BetterLifter site

Privacy policy and support pages for the BetterLifter app, served by GitHub Pages at
https://kaumah.github.io/betterlifter-site/ (`/privacy/`, `/support/`). Plain HTML + one stylesheet, no build step.
Keep the privacy policy in step with the app's permissions (Info.plist usage strings, entitlements) and bump its
effective date when it changes.
